🐝 Bee Swarm Push API

基于 Cloudflare Workers 的多渠道消息推送服务

🔐 认证方式

支持三种认证方式：

• Bearer Token - JWT Token

• X-API-Key - API Key

• X-Token - 访问令牌

📡 推送渠道

支持 16 种推送渠道：

Telegram、DingTalk、WeCom、企业微信、ServerChan、 Bark、PushPlus、NTFY、Slack、Discord、Teams、Gotify、LINE、WebHook、Feishu、Email

☁️ Cloudflare 服务

深度集成 Cloudflare 免费服务：

Workers AI、Vectorize、KV、 D1、R2、Durable Objects、Analytics Engine、Queue

🔧 API 前缀

• 公开接口：/api/*

• 管理接口：/api/admin/*

• Cloudflare：/api/cloudflare/*

• Webhook：/api/admin/webhook/push

🔑 认证示例

1. 获取访问令牌 (Token)

# 请求
POST /api/token
Content-Type: application/json

{
  "email": "user@example.com",
  "password": "your_password"
}

# 响应
{
  "token": "xxx",
  "refreshToken": "xxx",
  "expiresAt": 1234567890
}

2. 获取 API Key

# 方式一：使用 Token 获取（GET）
GET /api/apikey?token=your_token

# 方式二：使用用户名密码（POST）
POST /api/apikey
Content-Type: application/json

{
  "username": "user@example.com",
  "password": "your_password"
}

📨 推送消息示例

同步推送

# 发送推送（需要认证）
POST /api/admin/push
Authorization: Bearer {token}
Content-Type: application/json

{
  "title": "服务器告警",
  "body": "CPU 使用率超过 90%",
  "channels": ["telegram", "dingtalk"],
  "url": "https://example.com/alert"
}

# 响应
{
  "success": true,
  "message": "推送完成: 2 成功, 0 失败",
  "results": [
    { "channel": "telegram", "success": true, "message": "发送成功" },
    { "channel": "dingtalk", "success": true, "message": "发送成功" }
  ]
}

异步推送（使用队列）

# 异步推送，立即返回 requestId
POST /api/admin/push
Authorization: Bearer {token}
Content-Type: application/json

{
  "title": "批量任务通知",
  "body": "您有 100 条消息待处理",
  "channels": ["telegram"],
  "async": true
}

# 响应（立即返回）
{
  "success": true,
  "message": "推送已加入队列",
  "requestId": "uuid-here",
  "async": true
}

使用 Webhook 触发推送

# Webhook 推送（使用 API Key）
POST /api/admin/webhook/push
X-API-Key: your_api_key
Content-Type: application/json

{
  "title": "CI/CD 通知",
  "content": "构建 #123 完成",
  "channels": ["wework"]
}

📝 模板使用示例

创建模板

POST /api/admin/templates
Authorization: Bearer {token}
Content-Type: application/json

{
  "name": "服务器告警模板",
  "title": "{{severity}} 告警: {{server}}",
  "content": "服务器 {{server}} 发生 {{issue}}，请及时处理。",
  "channels": ["telegram", "dingtalk"],
  "useMarkdown": true
}

使用模板发送

POST /api/admin/push
Authorization: Bearer {token}
Content-Type: application/json

{
  "templateId": "template_uuid",
  "templateVariables": {
    "severity": "严重",
    "server": "DB-Primary",
    "issue": "磁盘空间不足"
  },
  "channels": ["telegram"]
}

预览模板变量替换

POST /api/admin/templates/{id}/preview
Authorization: Bearer {token}
Content-Type: application/json

{
  "variables": {
    "severity": "严重",
    "server": "DB-Primary"
  },
  "autoVars": true
}

# 响应
{
  "title": "严重 告警: DB-Primary",
  "content": "服务器 DB-Primary 发生 undefined，请及时处理。"
}

⏰ 定时推送示例

创建一次性定时推送

POST /api/admin/scheduled
Authorization: Bearer {token}
Content-Type: application/json

{
  "title": "定时提醒",
  "content": "该喝水了！",
  "channels": ["telegram"],
  "scheduledAt": "2024-12-25T09:00:00Z",
  "scheduleType": "once"
}

创建重复定时推送

# 每天早上 9 点推送
POST /api/admin/scheduled
Authorization: Bearer {token}
Content-Type: application/json

{
  "title": "每日日报",
  "content": "今日工作已汇总，请查收。",
  "channels": ["telegram"],
  "scheduleType": "recurring",
  "recurringType": "daily"
}

# 使用 Cron 表达式（每周一到周五 9:00）
{
  "title": "工作提醒",
  "content": "早上好，开始工作！",
  "channels": ["telegram"],
  "scheduleType": "recurring",
  "recurringType": "cron",
  "cronExpression": "0 9 * * 1-5"
}
🤖 AI 功能示例

使用 AI 生成推送内容

POST /api/admin/ai/generate
Authorization: Bearer {token}
Content-Type: application/json

{
  "prompt": "生成一条服务器磁盘空间告警的推送消息",
  "type": "both",
  "language": "zh"
}

# 响应
{
  "title": "⚠️ 服务器告警：磁盘空间不足",
  "content": "服务器 DB-Primary 的磁盘空间已使用 95%，请及时清理或扩容，以避免影响服务正常运行。"
}

检查 AI 服务状态

# 公开接口，无需认证
GET /api/ai/available

# 响应
{
  "available": true
}
